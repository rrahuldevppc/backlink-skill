# The five off-page tiers

Directory listings alone do not rank a site. They are the foundation layer —
trust and consistency, very little ranking power on their own. Build outward in
this order.

## Tier 1 — Directories & citations  *(the default batch)*

Business directories, local citations, classifieds.

- Volume: 30–50 per client
- Purpose: brand entity, NAP consistency, trust signals
- Mostly nofollow; value comes from the platform page ranking and from brand
  SERP real estate
- Fully covered by `references/directory-submission.md`

## Tier 2 — Web 2.0 & profiles  *(where real equity starts)*

| Platform | Note |
|---|---|
| Blogger | Loosest rules, dofollow |
| WordPress.com | Dofollow — build 3+ posts over 2–3 weeks, not all at once |
| Google Sites | Near-zero risk, good for a mini-site with NAP |
| Substack | Dofollow, verified |
| Medium | **Nofollow**, and promo blogs get suspended without notice — ORM presence only |
| Hashnode / dev.to | Dev and SaaS clients only |
| Tumblr | Outbound links are redirect-wrapped — no equity |
| Notion (free) | `noindex` — not a link target |

**Post spec:** 450–700 words, **unique per platform** (syndicating one post
across all of them is the biggest footprint you can leave), genuinely useful,
exactly one in-body branded link, one 1200×675 image, a locally specific detail,
title as a question or how-to at 50–60 chars.

## Tier 3 — Document & infographic distribution

**Docs/slides:** SlideShare → Speaker Deck → Scribd → Calameo → AnyFlip →
FlipHTML5 → Issuu → Yumpu → SlideServe. Avoid anything with an expiring link.

- One master deck per client/topic, two exports: 16:9 PPTX at 1920×1080, and a
  PDF **with embedded clickable hyperlinks** (flipbook viewers preserve links;
  slide-image viewers flatten them)
- 10–16 slides, 30–60 words per slide (the transcript is what gets indexed),
  slide 1 is a keyword title card, last slide is CTA + full URL + NAP
- Put the full `https://` URL on a slide — description links get stripped, the
  in-deck URL survives
- Under 20MB, fonts embedded

**Infographics:** master PNG 800px wide × 2000–4000px tall, under 1.5MB, footer
carrying logo + URL + 3–6 real cited sources. Derivatives: 735×1102 (Pinterest),
1200×630 (OG), 1400×1050.

**Publish on the client's own site first**, with an embed-code box — directories
link to that canonical page. Realistic ceiling ~14 placements per asset.

## Tier 4 — Video

YouTube (phone-verify the account), Vimeo, Dailymotion, Rumble, archive.org.
Avoid platforms with a brand-risk audience for professional clients.

**Minimum viable video, no editor needed:** 60–120s slideshow MP4 — 6–10 stills
at 1920×1080, a 150–170 word script, TTS voiceover, slow zoom, crossfades, and
burned-in captions (it has to work muted). H.264 1080p, CRF 21–23, ≈40–80MB.
Cut a 9:16 version for Shorts/Reels. One video → 8–10 platforms; only the
metadata changes.

## Tier 5 — Editorial, guest posts & digital PR

The only tier that moves competitive keywords. Relationship work, slowest,
highest value, and largely manual. Media sites are **pitches, not listings** —
route them out of the batch flow entirely.

## Asset-tier rules

Tiers 3 and 4 add one step before packs: the asset has to exist and pass intake
checks. Creating the asset is a separate job from distributing it — this skill
distributes. The **first asset per client needs explicit sign-off** before the
batch goes out; later batches run automatically.

## Recommended sequence for a new client

Tier 1 (foundation, 30–50) → Tier 2 (equity, 4 platforms) → Tier 3 (leverage,
one asset → ~14 links) → Tier 4 (one video → 8–10) → Tier 5 (ongoing).
