# Playbooks

One file per site: `playbooks/<domain>.md`.

After anyone submits to a site — successfully or not — the process gets written
down here: the steps that worked, the pack-field → form-field mapping, the
site's own category vocabulary, image requirements, where the live URL appears,
and what blocked where.

Next time that site comes up, the skill reads the playbook and fills the form
directly instead of rediscovering it. `git pull` and one person's learning
becomes the whole team's speed.

Start from `_TEMPLATE.md`.

**Process only.** Never credentials, never client content.
